# Personal & Hometown Portfolio Web Application

A responsive, multi-page dynamic web application built to showcase personal background, resume details, hometown highlights (Gümüşhane), and local sports culture, featuring user authentication, dynamic form handling, and external REST API integration.

## Tech Stack
* **Frontend:** HTML5, CSS3, Bootstrap, JavaScript (ES6+)
* **Backend & Auth:** PHP (Session Management & Form Processing)
* **External API:** The Movie Database (TMDB) REST API

## Key Features
* **User Authentication Flow:** Login and logout functionality with session control redirecting authenticated users to the main dashboard.
* **Dynamic Movie Search (API Integration):** Fetches and renders real-time movie posters, release dates, and metadata asynchronously using the **TMDB API** (`İlgi Alanlarım` / Interests module).
* **Interactive Contact Form & Validation:** Client-side and server-side form validation with dynamic result rendering upon submission (`İletişim` module).
* **Structured Multi-Page Architecture:** Dedicated sections for personal biography (`Hakkımda`), academic & technical resume (`Özgeçmiş`), hometown tourism guide (`Şehir` - Gümüşhane), and local football club history (`Takım` - Gümüşhanespor).
